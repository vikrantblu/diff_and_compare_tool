# Security Policy

## Supported Versions

We provide security updates and patches for the current release line:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **diff_and_compare_tool**, please report it responsibly:

1. **Do not** file a public GitHub issue.
2. Use **GitHub Private Vulnerability Reporting** via the [Security tab](https://github.com/vikrantblu/diff_and_compare_tool/security/advisories/new).
3. Provide:
   - A detailed description of the vulnerability and potential impact
   - Clear reproduction steps or Proof of Concept (PoC)
   - Affected component(s) (e.g. Secret Scrubber, Archive VFS, Remote Manager, Parser)

We take security seriously and will acknowledge receipt within 48 hours, investigate the issue, and release a fix in a coordinated disclosure.
